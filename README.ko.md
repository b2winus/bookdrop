# Bookdrop

[English](README.md) | 한국어

카카오 책 검색, 알라딘, Google Books, Open Library에서 책 정보를 가져와 Obsidian 노트로 만드는 플러그인입니다. 책을 고르면 다른 소스에서 ISBN으로 빠진 정보(쪽수, 목차 등)를 채워 넣고, 노트 안에서 **독서 기록**(읽기 상태, 날짜, 별점, 읽은 쪽수, 인용구)을 남기고 **내 책장** 보기로 모아 볼 수 있습니다.

## 기능

| 명령 | 하는 일 |
|---|---|
| **책 검색해서 새 노트 만들기** (리본 📖 아이콘) | 검색 → 선택 → 템플릿대로 `Books/` 폴더에 책 노트 생성 |
| **커서 위치에 책 정보 삽입** | 지금 노트의 커서 자리에 책 정보 블록 삽입. 텍스트를 선택한 채 실행하면 그 텍스트로 바로 검색 |
| **이 책 기록하기** | 읽기 상태, 별점, 한줄평, 남기고 싶은 문장(쪽수 포함), 메모를 한 창에서 입력. 노트를 만든 직후 자동으로 열림(끌 수 있음) |
| **읽기 상태 바꾸기** | 읽기 전 / 읽는 중 / 다 읽음 / 중단 중에서 고름 |
| **이 책 읽기 시작 / 다 읽음으로 표시** | 상태와 오늘 날짜를 한 번에 기록 |
| **이 책 별점 매기기** | 별 1~5개 (3.5처럼 입력하면 반 개도 가능) |
| **읽은 쪽수 기록** | 지금까지 읽은 쪽을 기록. 마지막 쪽이면 다 읽음으로 표시 |
| **이 책에 인용구 추가** | 선택한 문장(또는 입력한 문장)을 쪽수와 함께 **인용** 아래에 추가 |
| **내 책장 보기 만들기** | 표지 갤러리가 있는 Bases 파일 생성 |
| **현재 노트 프런트매터에 책 정보 채우기** | 노트의 `isbn` → `title` → 파일 이름 순으로 검색어를 정해 속성(저자, 출판사, ISBN, 표지 등)을 채움 |

- 제목, 저자, ISBN(하이픈 있어도 됨) 어느 것으로도 검색됩니다. ISBN이면 정확 검색으로 바뀝니다.
- 검색 창에서 카카오, 알라딘, Google Books, Open Library를 바로 바꿀 수 있습니다. 결과가 없으면 한글 검색어는 국내 소스를, 그 밖의 검색어는 해외 소스를 먼저 이어서 찾습니다(설정에서 끌 수 있음).
- **정보 보강:** 책을 고른 뒤 다른 소스에서 ISBN으로 조회해 **비어 있는 항목만** 채웁니다. 이미 있는 값은 바꾸지 않고, 잘려 온 짧은 책 소개만 더 긴 소개로 바꿉니다.
- 템플릿에서 `{{#toc}}…{{/toc}}`처럼 감싸면 그 정보가 있을 때만 해당 부분이 들어갑니다.
- ↑↓로 고르고 Enter로 선택합니다. 한글 입력 중의 Enter는 무시합니다.
- 카카오 결과는 작은 썸네일 대신 원본 크기 표지 주소를 찾아서 넣습니다.
- 저장 폴더는 설정에서 보관소 폴더 목록을 보고 고를 수 있습니다. **노트 만들 때마다 폴더 고르기**를 켜면 책을 고른 뒤 매번 저장 폴더를 묻습니다.
- 화면과 기본 템플릿을 **한국어와 영어**로 쓸 수 있습니다. 기본은 Obsidian의 언어 설정을 따르고, 플러그인 설정의 **언어**에서 직접 고를 수도 있습니다.
- 데스크톱과 모바일에서 모두 동작합니다(Obsidian의 `requestUrl` 사용).

## 설치 (직접 설치)

1. 보관소의 `.obsidian/plugins/bookdrop/` 폴더를 만듭니다.
2. `main.js`, `manifest.json`, `styles.css` 세 파일을 그 폴더에 넣습니다.
3. Obsidian → 설정 → 커뮤니티 플러그인에서 **Bookdrop**를 켭니다.

## API 키

### 카카오 (국내서에 추천)
1. https://developers.kakao.com 에 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. 앱을 만든 뒤 **앱 키**의 **REST API 키**를 복사합니다.
3. 플러그인 설정에 붙여 넣고 **연결 확인**을 누릅니다.
   - 401 오류가 나면 REST API 키가 아닌 다른 키(JavaScript 키 등)를 넣었는지 확인하세요.

### 알라딘 (국내서 쪽수·목차)
1. [알라딘 TTB](https://www.aladin.co.kr/ttb/wblog_manage.aspx)에서 TTB 키를 받습니다(무료, 알라딘 계정 필요).
2. 플러그인 설정의 **알라딘 TTB 키**에 넣고 **연결 확인**을 누릅니다.
   - 알라딘 결과를 보여 줄 때는 알라딘이 요구하는 출처 문구("도서 DB 제공: 알라딘 인터넷서점")가 검색 창 아래에 표시됩니다.

### Open Library (외서, 키 필요 없음)
따로 설정할 것이 없습니다.

### Google Books (외서에 강함, 키는 선택)
키 없이도 동작합니다. 자주 쓰다 429(요청 한도) 오류가 나면 Google Cloud Console에서 **Books API**를 사용 설정하고 API 키를 만들어 넣으세요.

## 템플릿

`{{변수}}` 형태로 씁니다. 필터를 붙일 수 있습니다.

| 필터 | 결과 예시 | 용도 |
|---|---|---|
| `{{title}}` | 미움받을 용기 | 본문 |
| `{{title:json}}` | `"미움받을 용기"` | 프런트매터 (콜론·따옴표가 있어도 안전) |
| `{{authors:json}}` | `["기시미 이치로","고가 후미타케"]` | 프런트매터 목록 |
| `{{authors:link}}` | `[[기시미 이치로]], [[고가 후미타케]]` | 본문 링크 |
| `{{authors:linkjson}}` | `["[[기시미 이치로]]","[[고가 후미타케]]"]` | 프런트매터 링크 목록 |
| `{{toc:list}}` | `- 머리말`<br>`- 첫 번째 밤…` | 글머리표 목록 (목록이나 여러 줄 텍스트) |
| `{{#series}}시리즈: {{series}}{{/series}}` | 시리즈: … (값이 없으면 통째로 빠짐) | 값이 있을 때만 넣을 부분 |

변수: `title` `subtitle` `originalTitle` `author` `authors` `translator` `translators` `publisher` `publishDate` `publishYear` `isbn` `isbn10` `isbn13` `pageCount` `series` `categories` `subjects` `description` `toc` `coverUrl` `link` `price` `language` `source` `sources` `status` `today`

표지 주소가 없으면 `![...]()`처럼 깨진 이미지 줄은 자동으로 지웁니다.

**소스별 차이**

| 항목 | 카카오 | 알라딘 | Google Books | Open Library |
|---|:-:|:-:|:-:|:-:|
| 제목, 저자, 출판사, 출간일, ISBN, 표지 | ✓ | ✓ | ✓ | ✓ |
| 역자 | ✓ | ✓ | — | — |
| 원제, 시리즈 | — | ✓ | — | — |
| 쪽수 | — | ✓ | ✓ | ✓ |
| 목차 | — | ✓ | — | — |
| 분류·주제 | — | 분류 | 분류 | 주제어 |
| 책 소개 | 짧게 잘림 | 전체 | 전체 | — |

## 독서 기록

### 기록 창

책 노트를 만들면 바로 **기록 창**이 열립니다. *설정 → 독서 기록 → 노트를 만든 뒤 바로 기록 창 열기*에서 끌 수 있고, 언제든 **이 책 기록하기** 명령으로 다시 열 수 있습니다.

- **읽기 상태:** 읽기 전 / 읽는 중 / 다 읽음 / 중단. 상태에 맞춰 날짜 칸이 *읽기 시작한 날* 또는 *다 읽은 날*로 바뀝니다.
- **내 별점:** 별을 클릭합니다. 별의 왼쪽 절반을 누르면 반 개입니다. 키보드로는 ← → 반 개씩, 1~5, 0은 지우기입니다.
- **한줄평**, **남기고 싶은 문장**(쪽수와 함께), **메모**(날짜와 함께 저장)를 입력합니다.
- **Ctrl/Cmd + Enter**로 저장하고, **건너뛰기**를 누르면 아무것도 바꾸지 않고 닫습니다.

설정의 **새 노트의 읽기 상태**를 바꾸면 새 노트가 *읽는 중*이나 *다 읽음*으로 시작합니다.

### 속성

책 노트를 연 상태에서 명령 팔레트로 실행하세요(단축키를 지정해 두면 편합니다). 아래 속성에 기록됩니다.

| 속성 | 기록하는 명령 | 예 |
|---|---|---|
| `status` | 읽기 상태 바꾸기, 읽기 시작, 다 읽음으로 표시, 읽은 쪽수 기록 | `읽는 중` |
| `started` | 읽기 시작 (비어 있을 때만) | `2026-10-26` |
| `finished` | 다 읽음 | `2026-11-20` |
| `rating` | 별점 매기기 — 정렬·필터용 숫자 | `4.5` |
| `stars` | 별점 매기기 — 같은 별점을 별표로 | `★★★★½` |
| `one_liner` | 이 책 기록하기 — 한줄평 | `용기에 관한 책` |
| `progress` | 읽은 쪽수 기록 (다 읽으면 전체 쪽수로) | `120` |

- 상태 이름은 **설정 → Bookdrop → 독서 기록**에서 바꿀 수 있습니다. 한국어·영어 기본 이름은 언제나 알아봅니다.
- **인용구**는 노트의 **인용** 제목(설정에서 변경 가능) 아래에 쪽수와 함께 `> 문장` / `> — p. 23` 형태로 쌓입니다. 문장을 선택한 채 실행하면 그 문장이 바로 들어갑니다.
- **내 책장 보기:** *내 책장 보기 만들기* 명령(또는 설정의 버튼)을 누르면 파일 이름을 묻습니다. 기본값은 *내 책장*이고 원하는 이름으로 바꿀 수 있으며, 책 폴더에 그 이름의 `.base` 파일이 생깁니다. 입력한 이름은 다음번에도 기본값으로 나오고, 같은 이름의 파일이 이미 있으면 그 파일을 엽니다. 표지 갤러리와 *읽는 중*, *올해 읽은 책*, *다 읽은 책*, *읽을 책* 보기가 들어 있고, `#book` 태그가 있거나 책 폴더에 있는 노트가 대상입니다. Bases는 Obsidian 1.9 이상에서 동작합니다.

**네트워크 사용:** 검색어나 고른 책의 ISBN을 사용하는 소스에만 보냅니다(`dapi.kakao.com`, `www.aladin.co.kr`, `www.googleapis.com`, `openlibrary.org`). 각 소스는 **정보 보강** 설정에서 끌 수 있습니다. API 키는 보관소 안의 플러그인 `data.json`에만 저장되고, 사용 기록은 어디에도 보내지 않습니다.

## 개발

```bash
npm install
npm run dev     # 변경을 감시하며 main.js 빌드
npm run build   # 타입 검사 + 배포용 빌드
```

개발할 때는 이 폴더를 보관소의 `.obsidian/plugins/bookdrop/`에 두거나 심볼릭 링크를 걸고, **Hot Reload** 플러그인을 쓰면 편합니다.
